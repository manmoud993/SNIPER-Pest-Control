# SNIPER Pest Control

نظام إدارة ومتابعة خدمات مكافحة الحشرات.

## التشغيل

```bash
npm start
```

ثم افتح `http://localhost:3000`.

## دخول المدير الافتراضي
- اسم المدير: `المدير`
- كلمة المرور: `1234`

غيّر كلمة المرور من الإعدادات بعد أول دخول.

## الوظائف
- حجز خدمة من صفحة العميل
- إدارة الحجوزات والعملاء
- إدارة الأسعار
- تحديد خطة العمل والموعد والسعر
- تأكيد ومتابعة الحجز
- إنشاء تقرير بعد المعالجة
- طباعة التقرير أو حفظه PDF
- تغيير اسم المدير وكلمة المرور

> ملاحظة الاستضافة: ملف `data.json` يتم إنشاؤه تلقائيًا عند التشغيل. للاستعمال التجاري طويل الأمد يفضّل نقل البيانات إلى قاعدة بيانات دائمة قبل تخزين بيانات العملاء بكثافة.
